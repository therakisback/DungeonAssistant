# DungeonAssistant

This repository primarily acts as a way to put all my projects in one place.
I created a dungeon master AI assistant for UCD's Generative AI class, using OpenAI's Responses API as the core AI.

This assistant is designed to ease the coginitive load on a D&D dungeon master, as has been given a wide set of tools to assist whenever required. It has also been built with failure recovery for a set of common API errors that can occur.

More detail is outlined in the python notebook or the report.
