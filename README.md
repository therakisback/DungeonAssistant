# DungeonAssistant

This repository serves as an easy way to view the final project for the UCD Generative AI course. I created a project using OpenAI's Responses API for ChatGPT, alongwith other APIs, in order to create an AI assistant for Dungeon Masters in the table-top role playing game Dungeons & Dragons.

The project must be run in google colab, as was specified in the assignment, however the code can be viewed as a normal .ipynb file. This version of the Colab will not work, as it does not have the API keys stored for security reasons.
  https://colab.research.google.com/drive/1Rdp8ZOzBANLu-PCFhFaopCWnscf6i4xA?usp=sharing

This assistant is designed to ease the coginitive load on a D&D dungeon master, as has been given a wide set of tools to assist whenever required. It has also been built with failure recovery for a set of common API errors that can occur.

More detail is outlined in the python notebook and the report.
